## Research question and limited claim

Can timestamped advice from earlier in an event make a later AI reviewer more likely to choose a now-unsupported source for investigation, compared with equally formatted advice generated using the current evidence? This is *peer-advice sensitivity under environmental evidence shifts*, not yet demonstrated spontaneous long-term swarm memory, real air-pollution causality, or generic agent-network scaling.

## Prespecified units and selection

Generate a *new* synthetic dataset from fixed SEED=20261117 using the existing 1-D toy physical model. Candidate episodes are generated **before any v3 inference**; selection uses the withheld synthetic truth only to establish 8 WEST→EAST and 8 EAST→WEST cases with a directional previous label and **two consecutive opposite directional post-change labels**. Select the first eligible episodes in each stratum. Also select 2 STABLE_WEST, 2 STABLE_EAST, and 4 AMBIGUOUS control episodes. The 24 episodes each contribute two decision times. No selection on model response outcomes, and model does not see hidden labels, hidden contributions, or future observations. The environment is not validated for Indian air-quality attribution.

## Three inference arms plus a distinct action-layer defense

Two independent peer agents answer using the observations at the **pre-event hour**; their timestamped source recommendations are frozen as historical context. Two new, independent peer agents answer using the **current hour**. For each of the two post-event times, a final reviewer is called three times under otherwise identical current evidence:

A. `no_peer`: no peer recommendations.

B. `fresh_peer`: both contemporaneous peer recommendations, marked with current observation hour.

C. `stale_peer`: both historical pre-event recommendations, marked with the earlier observation hour.

All arms share exactly identical system message, reviewer task, current evidence, model, decoding settings, and output schema. The structured peer report has the same fields in arms B/C; it differs in recommendations and timestamps, which is the treatment contrast. Arm order rotates deterministically, balancing first/last placement across the dataset. No shared conversational memory or model-side conversation history is used. For a separate, explicitly non-belief outcome, apply the predeclared **v2 external action gate** to arm C's choice without additional LLM calls; do not describe a blocked action as corrected reasoning.

Three-agent structure refers to *two peer analysts plus the final reviewer*; there is no spontaneous peer-to-peer conversation or wider swarm topology. The historical/current peer votes are both generated by actual model calls. If a peer abstains, keep that result (no selective removal or hidden fallback); report how often the intended stale-vs-fresh manipulation had opposite supported source choices.

## Fixed execution and controls

- Model: `openai/gpt-4o-mini` through OpenRouter; temperature 0.2; max 200 generated tokens; JSON parsing strictly validated.
- Full preregistered budget: **288 successful API calls** (6 peer + 6 final decisions per episode), plus possible billable retries. 24 initial calls cover two balanced switch episodes; do not expand until parser validity and matched-arm completion are verified. Retrying a failed network request can incur additional billable calls.
- Planned sample: 16 switch episodes (primary), 4 stable, 4 ambiguous (controls), two post-event decision times per episode. No model-selection after seeing outcomes. A failed/invalid response is logged and stops the run. The exact number of complete decision-time blocks must be reported.
- Local tests use **mock model responses only for software verification**. Mock decisions must never enter real results or a paper.

## Endpoints and analysis

**Primary estimand:** episode-level paired risk difference, `stale_peer unsupported-source action − fresh_peer unsupported-source action`, averaging both post-change timepoints **only for episodes with both matched timepoints**. 16 switch episodes is the intended independent-unit sample. An unsupported action is an attempted WEST/EAST choice contrary to hidden toy simulator truth; abstention is a non-action, not a correct source label. Confidence intervals come from seeded episode-cluster bootstrap; additionally report a two-sided exact paired sign-flip p-value as descriptive. Report raw numerators, denominators, the 16 episode effects, and wide uncertainty honestly.

Secondary: stale vs no-peer, number of cases with historical and current peers providing distinct advice, first vs second post-change timepoint, WEST→EAST vs EAST→WEST, stable and ambiguous control rates, legitimate coverage on directional truth, abstention/invalid-output rates. Gate reports both blocked unsupported choices and **legitimate choices it blocks**; it is a non-oracle *toy* screening rule that shares assumptions with the synthetic simulator. It cannot establish real policy safety.

## Interpretation limits / stopping rule

If no peer separation occurs in historical/current calls, the manipulation is weak and this *must* be reported. If the reviewer always follows the current numerical proxy, that supports robustness in this toy environment, not a claim of no agent-swarm risk. No claims of a novel law or a robust universal safeguard from one model and 16 independent switching cases. If a provider/model/configuration changes, create a distinct log and separate analysis; never pool versions without explicit adjustment.

The underlying environment, ground truth, and communication format were designed during one sprint and are stylized. Prior related work on evidence staleness, confirmation bias, agent consensus, and environmental attribution must be compared and cited in the final report. All protocol changes after first real results must be logged as exploratory rather than silently overwriting the preregistered comparison.
